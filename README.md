# KEIB 競馬予想

ブラウザだけで動く競馬予想ソフトです。馬柱（過去5走）からスピード指数・展開・適性を数値にし、レースを何万回もシミュレーションして各馬の勝率を出し、オッズと比べて期待値の高い買い目を提案します。サーバーは不要で、ビルドすると1つの HTML ファイルになります。

![KEIB の予想画面](docs/screenshot.png)

> サンプルの馬・騎手・調教師・種牡馬・レースはすべて架空のもので、実在のものとは関係ありません。予想は参考情報であり、的中や利益を保証しません。馬券の購入は20歳から。

## できること

| 画面 | 内容 |
| --- | --- |
| 予想 | 出馬表に印（◎○▲△☆）・AI指数・勝率・複勝率・期待値を表示。行を開くと馬柱、評価の内訳、着順分布、オッズの修正・出走取消 |
| 展開予想 | 通過順から脚質を推定し、逃げ・先行馬の数からペース（H/M/S）を予想。隊列図つき |
| 買い目 | 予算と戦略（的中重視・バランス・高配当）から、7券種（単勝〜三連単）の買い目と金額を提案。印からの定番フォーメーションの的中率・回収率も表示 |
| 重み付け | スピード指数・近走成績・上がり・騎手・適性・展開・枠順・状態・人気の9項目をスライダーで調整。プリセットあり |
| バックテスト | 結果のわかっている架空の過去レースで、予想と買い方の的中率・回収率・累積収支・確率の当たり具合を検証 |
| データ | 自分で用意した出馬表・過去走を CSV / JSON で取り込んで予想（Shift_JIS の CSV も可） |

馬場状態（良〜不良）を切り替えると、道悪適性などを反映して予想が変わります。設定と取り込んだレースはブラウザに保存されます。

## すぐに使う

```bash
npm install
npm run build     # dist/index.html を作る
npm run serve     # http://localhost:8080 で開く
```

`dist/index.html` は1ファイルで完結しているので、ダブルクリックで直接開くこともできます。開発中は `npm run dev`（変更を監視して自動ビルド）と `npm run serve` を並べて使います。

## 公開する

### claude.ai の Artifact（公開済み）

ビルドで作られる `dist/artifact.html` を claude.ai の Artifact として公開しています：<https://claude.ai/artifact/SEpXBGjVE5ftK8aWq191x4>

### Cloudflare Tunnel（手元の PC から一時的に公開）

1. [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) をインストール（macOS: `brew install cloudflared`、Windows: `winget install --id Cloudflare.cloudflared`）
2. `npm run tunnel` を実行
3. 表示される `https://xxxx.trycloudflare.com` をスマホなどで開く

PC を閉じたり Ctrl+C で止めたりすると見られなくなります。アカウント不要の一時 URL です。

### GitHub Pages（常設の URL）

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. **Actions** タブの「GitHub Pages」→ **Run workflow** で、公開したいブランチを選んで実行する
3. 以後は `main` ブランチへの push ごとに、`.github/workflows/pages.yml` が自動でテスト・ビルドして公開します

公開先は `https://<ユーザー名>.github.io/keib/` です。

## 予想のしくみ

1. **スピード指数**：走破タイムを競馬場・芝ダート・距離・馬場ごとの基準タイムと比べて数値化（80 が条件戦の平均、重賞の勝ち馬で100前後）。
   `指数 = 80 + 1000 ×（基準タイム − 走破タイム）÷ 基準タイム + 2 ×（斤量 − 55）`
2. **ファクター**：近走の着順・着差、上がり3F順位、騎手成績、距離・コース・馬場・芝ダ・回り・血統の適性、展開（脚質×ペース×直線の長さ）、枠順（コース別の内外の有利不利）、状態（休み明け・叩き2戦目・斤量増減・馬体重増減・年齢）、人気。
3. **AI指数**：各ファクターをレース内で中心化・標準化して重みを掛けて合計。既定の重みは架空の学習用2,000レースで1〜3着の順番を最もよく説明するように推定（プラケット・ルース尤度、`npm run calibrate`）。
4. **モンテカルロ・シミュレーション**：「能力スコア＋正規分布の揺らぎ」で既定2万回レースを走らせ、勝率・連対率・複勝率と全券種の組み合わせ確率を集計。揺らぎは成績の安定度や出走数に応じて馬ごとに変えます。
5. **期待値**：`期待値 = 的中確率 × オッズ`。単勝以外のオッズは、単勝オッズに正規モデルを当てはめて推定します。AIとオッズの見立てがずれた馬券ほど期待値が高く見える「勝者の呪い」を抑えるため、期待値の計算ではオッズの確率を混ぜます（標準50%、画面で変更可）。

詳しくはアプリの「しくみ」画面を見てください。

## 自分のデータで予想する

「データ」画面でレース情報を入れ、出馬表と過去走の CSV を貼り付ける（またはファイルを選ぶ）と予想できます。「見本を入れる」で形式を確認できます。

出馬表（1行1頭）

```csv
枠,馬番,馬名,性齢,斤量,騎手,馬体重,増減,単勝オッズ,父,騎手勝率,騎手複勝率
1,1,サンプルアロー,牡4,58,青木,486,+4,3.6,,15.2%,38.0%
```

過去走（1行1走、馬番で出馬表と結び付け）

```csv
馬番,日付,競馬場,レース名,クラス,芝ダ,距離,馬場,頭数,着順,タイム,着差,上がり3F,上がり順位,通過順,斤量,騎手
1,2026-09-06,中山,サンプル特別,3勝,芝,1800,良,14,2,1:46.8,0.1,34.6,2,5-5-4-3,58,青木
```

必須は出馬表の「馬番・馬名」と過去走の「馬番（または馬名）・日付・距離」です。列の順番は自由で、全角数字やタブ区切りも読めます。誤りがあると行番号つきで表示します。JSON での書き出し・取り込みもできます。

## 検証結果（架空データ）

学習に使っていない架空の1,000レースでのバックテスト（`RACES=1000 npm run evaluate`、既定の重み・1点100円）。

| | 勝率 | 複勝率 | 単勝回収率 |
| --- | --- | --- | --- |
| AI の◎ | 25.0% | 51.4% | 87.3% |
| 1番人気 | 29.4% | 58.6% | 88.2% |

| 買い方 | 的中率 | 回収率 |
| --- | --- | --- |
| 複勝 ◎ | 51.4% | 76.3% |
| 馬連 ◎-○ | 7.7% | 70.4% |
| ワイド ◎-○▲ | 16.3% | 71.3% |
| 三連複 ◎軸 相手4頭 | 2.4% | 89.0% |
| 単勝 期待値1.2以上 | 4.3% | 59.4% |
| AI推奨（バランス・1R千円） | 4.1% | 58.8% |

架空の市場（オッズ）は「馬柱などの公開情報」と「市場だけが持つ情報」を組み合わせて作っているため、公開情報だけで計算する AI の予想はすでにオッズに織り込まれています。そのため回収率は100%を下回るのが普通で、これは実際の競馬でも同じです。AI の勝率の見積もり自体はよく当たっています（予測20〜30%の馬の実際の勝率は25.2%など）。

## 開発

```bash
npm test            # ユニットテスト（node:test）
npm run calibrate   # 学習用の架空レースで係数を推定し src/engine/calibration.js を更新
npm run evaluate    # 学習に使っていないレースでバックテスト
```

```
src/
  engine/      予想エンジン（指数・ファクター・モデル・シミュレーション・市場・買い目・バックテスト・取り込み）
  data/        架空データの生成器と名前リスト
  ui/          画面（予想・バックテスト・データ・しくみ）とグラフ
  main.js      アプリ本体（状態・イベント）
  styles.css   スタイル（ライト / ダーク）
  app.html     画面の骨組み
scripts/       ビルド・配信・Cloudflare Tunnel・校正・検証
test/          テスト
```

ビルドすると `dist/index.html`（単体で動く HTML）と `dist/artifact.html`（claude.ai の Artifact 用の断片）ができます。
